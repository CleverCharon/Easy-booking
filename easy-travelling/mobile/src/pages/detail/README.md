# 酒店详情页 (Detail Page) 技术归纳文档

## 1. 概述
该页面用于展示特定酒店的详细信息、房型列表及预订入口。采用沉浸式 UI 设计，集成了日期选择、房型切换、收藏、分享等核心交互功能。

## 2. 功能模块与实现

### 2.1 核心功能
- **沉浸式导航栏**:
  - 初始状态背景透明，页面滚动超过 `80px` 后渐变为深蓝色 (`#2C439B`)。
  - 包含返回按钮、页面标题（滚动后显示）、分享按钮、收藏按钮。
- **顶部轮播图 (Banner)**:
  - 聚合展示酒店封面图、详情图及各房型图片。
  - 底部叠加渐变遮罩 (`gradient-overlay`) 以增强文字可读性。
  - 显示评分 (`rating-badge`) 和“官方图片”标识。
- **信息概览卡片**:
  - 悬浮于 Banner 之上（通过负 margin 实现）。
  - 展示酒店名称（特殊字体）、星级、地址、特色服务标签。
- **日期选择器**:
  - 显示当前选中的入住/离店日期及共住晚数。
  - 点击弹出 `NutUI Calendar` 组件进行日期范围修改。
  - 修改日期后自动刷新酒店详情（重新获取该日期范围内的房型库存/价格）。
- **房型列表**:
  - 展示房型名称、图片、剩余库存、设施标签。
  - **状态区分**: 支持“可预订”与“已售罄”状态样式区分。
  - **自动选中**: 数据加载后自动选中第一个有库存的房型。
  - **价格展示**: 显示原价（划线）与当前优惠价。
- **底部操作栏**:
  - 左侧展示选中日期的总价预估。
  - 右侧“立即预订”按钮，点击跳转至订单创建页。

### 2.2 交互逻辑
- **收藏/取消收藏**:
  - 调用 `/favorites/add` 或 `/favorites/remove` 接口。
  - 操作前校验用户登录状态，未登录自动跳转登录页。
- **浏览记录**:
  - 页面加载成功后，自动调用 `/history/add` 记录用户浏览行为。
- **下拉刷新**:
  - 触发 `usePullDownRefresh`，重新并发加载酒店详情和收藏状态。

## 3. 接口调用

| 接口路径 | 方法 | 描述 | 参数示例 |
| :--- | :--- | :--- | :--- |
| `/hotels/${id}` | GET | 获取酒店详情及房型列表 | `check_in_date=...&check_out_date=...` |
| `/favorites/list` | GET | 获取用户收藏列表（用于高亮爱心） | `user_id=...` |
| `/favorites/add` | POST | 添加收藏 | `{ user_id, hotel_id }` |
| `/favorites/remove` | POST | 取消收藏 | `{ user_id, hotel_id }` |
| `/history/add` | POST | 添加浏览历史 | `{ user_id, hotel_id }` |

## 4. 样式亮点与处理

### 4.1 视觉设计 (SCSS)
- **配色系统**:
  - 主色调: 深蓝 `#2C439B` (导航栏、标题、按钮渐变)
  - 辅助色: 亮蓝 `#33C7F7` (图标、选中态、标签背景)
  - 点缀色: 粉色 `#DFA0C8` (优惠标签、爱心、标签背景)
- **层叠布局**:
  - `.info-card` 使用 `margin: -14px 16px 0` 实现向上覆盖 Banner 的卡片效果，增加页面立体感。
  - `z-index` 管理：导航栏 (100) > 底部栏 (90) > 信息卡片 (2) > Banner 图片 (1)。

### 4.2 特殊样式处理
- **Swiper 高度强制修正**:
  - 为了解决 Taro/NutUI Swiper 组件在不同设备上可能出现的高度坍塌或样式异常，在 `index.scss` 中使用了 `!important` 强制指定高度：
    ```scss
    .nut-swiper, .nut-swiper-inner, taro-swiper-core, ... {
      height: 100% !important;
      width: 100% !important;
    }
    ```
- **字体**:
  - 酒店名称使用了 `"华文新魏", "Times New Roman", serif`，营造高端优雅的视觉感受。

## 5. 数据处理与逻辑细节

- **图片聚合逻辑 (`useMemo`)**:
  - 将 `hotel.images` (详情图)、`hotel.main_image` (主图)、`hotel.image_url` (封面)、`room.image_url` (房型图) 全部合并并去重，形成完整的轮播图数据源。
- **日期处理**:
  - 使用 `dayjs` 库处理日期格式化 (`YYYY-MM-DD`) 和晚数计算 (`diff`)。
  - 路由参数 `checkIn/checkOut` 带有默认值兜底逻辑（默认为今天和明天）。
- **路由参数**:
  - 接收 `id` (酒店ID), `checkIn` (入住日期), `checkOut` (离店日期)。

## 6. 文件结构
- `index.tsx`: 主要 UI 结构与业务逻辑。
- `index.scss`: 页面样式定义。
- `index.config.ts`: 页面配置（开启下拉刷新、自定义导航栏样式 `navigationStyle: 'custom'`）。
