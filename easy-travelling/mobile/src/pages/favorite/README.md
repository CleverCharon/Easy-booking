# 收藏页 (Favorite Page) 技术归纳文档

## 1. 概述
收藏页是用户管理个人兴趣数据的核心页面，整合了“我的收藏”与“浏览历史”两大板块。页面提供了丰富的筛选、排序及批量管理功能，采用卡片式设计，视觉风格简洁现代。

## 2. 功能模块与实现

### 2.1 核心功能
- **双 Tab 切换**:
  - 支持“我的收藏” (`collected`) 和“浏览历史” (`viewed`) 两种模式切换。
  - 不同模式下调用的数据接口不同，但复用同一套列表渲染逻辑。
- **批量管理 (仅收藏 Tab)**:
  - 点击“管理”按钮进入编辑模式。
  - 支持单选、全选、反选操作。
  - 底部浮出操作栏，显示已选数量，支持批量取消收藏。
- **筛选与排序**:
  - **城市筛选**: 自动提取当前列表中所有酒店的城市，生成横向滚动的 Chip 列表。
  - **多维排序**: 支持“最近收藏”、“价格升/降序”、“评分降序”四种模式切换。
- **状态管理**:
  - **未登录态**: 展示空状态占位，引导用户前往登录。
  - **加载态**: 显示 Loading 提示。
  - **空数据态**: 展示缺省图，并提供跳转首页/列表页的按钮。
- **列表交互**:
  - 点击卡片跳转至酒店详情页。
  - 在“收藏”模式下，卡片右上角显示爱心图标，支持快捷取消收藏。
  - 在“历史”模式下，右上角显示“浏览”标签。

### 2.2 交互逻辑
- **数据同步**:
  - 使用 `useDidShow` 钩子，确保每次进入页面（包括从详情页返回）时都自动刷新数据。
  - 切换 Tab 或用户 ID 变化时也会触发数据刷新。
- **批量操作**:
  - 取消收藏前弹出二次确认模态框 (`Taro.showModal`)。
  - 操作成功后自动刷新列表并退出管理模式。

## 3. 接口调用

| 接口路径 | 方法 | 描述 | 参数示例 |
| :--- | :--- | :--- | :--- |
| `/favorites/list` | GET | 获取用户收藏列表 | `user_id=...` |
| `/history/list` | GET | 获取用户浏览历史 | `user_id=...` |
| `/favorites/remove` | POST | 取消收藏（支持批量并发调用） | `{ user_id, hotel_id }` |

## 4. 样式亮点与处理

### 4.1 视觉设计 (SCSS)
- **背景风格**:
  - 采用柔和的线性渐变背景 (`linear-gradient(180deg, #eef4ff 0%, ...)` )，营造清爽的视觉体验。
- **毛玻璃效果**:
  - 顶部导航栏和底部管理栏均使用了 `backdrop-filter: blur(8px)`，增强页面通透感。
- **卡片设计**:
  - 酒店卡片采用圆角 (`16px`) 和 阴影 (`box-shadow`)，悬浮感强。
  - 选中态 (`check-dot`) 使用主色调 (`#33c7f7`) 高亮。
- **字体**:
  - 标题栏使用了 `"华文新魏", "Times New Roman", serif`，与详情页保持一致的品牌调性。

### 4.2 特殊处理
- **数据标准化 (`normalizeHotel`)**:
  - 由于后端返回的收藏列表和历史记录列表字段结构可能不完全一致（如 `image` vs `main_image`，`price` vs `min_price`），前端实现了一个转换函数，将异构数据统一为 `HotelCard` 结构，保证 UI 渲染层的稳定性。
- **本地过滤与排序**:
  - 考虑到数据量通常不会过大，筛选（城市）和排序（价格/评分）逻辑均在前端通过 `useMemo` 实现，减少了后端接口的复杂度，且响应速度更快。

## 5. 数据结构

### 5.1 HotelCard 接口
```typescript
interface HotelCard {
  id: string
  name: string
  image: string
  score: number
  price: number
  tags: string[]
  address: string
  city: string
  reviewCount: number
}
```

## 6. 文件结构
- `index.tsx`: 页面逻辑核心，包含状态管理、数据获取、交互处理。
- `index.scss`: 页面样式定义，包含顶部栏、Tabs、卡片列表、底部管理栏等。
- `index.config.ts`: 页面基础配置。
